# Generation pipeline UX fidelity

Type: prototype
Status: resolved
Blocked by: 02, 03

## Question

Does a single-page flow (premise → progress → film player) feel right for generating and watching the short film?

## Answer

Yes. One composition: brand + premise form → live pipeline stages (screenplay → per-scene media) via SSE → cinema-style Film Player. No dashboard chrome. Prototype validated by shipping the real UI on the same flow (throwaway branch unnecessary; decision locked into the app). Media mode toggle: Video (default) | Stills.
